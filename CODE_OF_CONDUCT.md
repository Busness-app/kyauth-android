# Code of Conduct

KyAuth handles authentication data and local secrets. Treat contributors with the same care that the project gives user data.

## Our commitment

We welcome contributions from people of every age, disability, ethnicity, gender identity, experience level, nationality, race, religion, and sexual orientation.

## Expected behavior

- Discuss the work, not the person.
- Give specific technical feedback.
- Credit reports, ideas, and code from other contributors.
- Accept corrections and review in good faith.
- Protect private information and security reports.

## Unacceptable behavior

- Harassment, threats, slurs, or personal attacks.
- Deliberate misgendering or repeated use of a rejected name.
- Publication of private information without permission.
- Retaliation against a person who reports a conduct or security issue.

## Reviews

KyAuth can use adversarial reviews. A review can criticize a design or a patch. It must not criticize an author or contributor.

## Reporting

Report conduct problems privately to the project maintainer through the repository host. Do not publish a report in an issue.

Report security vulnerabilities through the repository security advisory process. Do not use a public issue for a security vulnerability.

## Enforcement

The maintainer can issue a warning, restrict participation, or ban a contributor. The response depends on the behavior and its effect.
